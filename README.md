# ANN Classification on Alphabets Dataset

## Overview

This project implements an Artificial Neural Network (ANN) to classify alphabet letters using TensorFlow/Keras. The model is trained on the Alphabets dataset and its performance is improved through hyperparameter tuning.

## Features

- Data preprocessing
- Label encoding
- Feature scaling
- Train-test split
- Baseline ANN model
- Hyperparameter tuning
- Model evaluation
- Confusion matrix
- Performance comparison

## Dataset

- **File:** `Alphabets_data.csv`
- **Target:** Alphabet (A-Z)
- **Features:** 16 numerical features

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow / Keras

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Output

- Baseline ANN Accuracy
- Tuned ANN Accuracy
- Classification Report
- Confusion Matrix
- Performance Comparison
